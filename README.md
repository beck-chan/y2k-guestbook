# y2k guestbook

Are you nostalgic for the days of the Geocities guestbooks? If so, learn how to build a fully functional retro-inspired guestbook using:

- Next.js to power your frontend application
- Supabase to power your application backend, and (optional) email notifications with Supabase Edge Functions
- Google OAuth 2.0 to gate your admin dashboard
- Vercel to deploy your finished application to the web
- (Optional) PostHog to capture analytics and display a visitor hit counter

Also provided are starter Cucumber tests to help you automatically verify default functionality that ships with the guestbook application with Playwright.
